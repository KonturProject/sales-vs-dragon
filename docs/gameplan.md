# Свин и загон — описание проекта (текущее состояние)

Карта файлов: [MAP.md](./MAP.md). Технические решения и их обоснование: [tech.md](./tech.md). Полная история решений: `.claude/plans/eventual-finding-peacock.md` (исходный утверждённый план — контекст уже устарел местами, актуальный статус смотри здесь).

## Концепция

Мини-игра-визуализация для отдела продаж, в пиксель-арт стиле. Команда из 6 РОПов-героинь (каждая — свой отдел) совместно толкает свина-талисмана (= недельный план продаж) вдоль дороги к загону (= выполненный план). Чья сделка закрылась в Google-таблице — та героиня наносит удар. Руководитель филиала (Валькирия) не привязана к отделу — мотивирует всю команду при каждой продаже. Админка с PIN задаёт недельный план.

## Источник правды по данным

Приватная Google-таблица → Google Apps Script Web App (standalone, не через Extensions-меню) → агрегированный JSON (сумма за неделю, разбивка по РОПам, план, метры) → фронтенд опрашивает раз в ~15 сек. Реальные ссылки и PIN — см. [MAP.md](./MAP.md#apps-script--бэкенд).
