# Отделы против дракона — описание проекта (текущее состояние)

Карта файлов: [MAP.md](./MAP.md). Технические решения и их обоснование: [tech.md](./tech.md). Концепция, правила механики и история переезда со «свина в загон»: [dragon-track.md](./dragon-track.md). (Репозиторий и URL Pages по-прежнему `svin-i-zagon` — по названию исходной игры.)

## Концепция

Мини-игра-визуализация для отдела продаж на офисном экране, в пиксель-арт стиле. Герои-маскоты 6 отделов отвоёвывают золото у дракона, сидящего на горе золота (= план). Когда отдел приносит деньги (новая продажа в Google-таблице) — его герой бьёт дракона. Неделя разбита на 5 равных дневных планов; дракон пятиголовый, и каждый пересечённый дневной план (20/40/60/80/100 % недельного) отрубает ему голову. Когда план недели закрыт — голов нет, на экране «Отделы победили дракона! План недели выполнен». Руководитель филиала (Круэлла) стоит в стороне, не привязана к отделу — подбадривает каждую продажу и празднует победу. Админка с PIN задаёт недельный план.

## Источник правды по данным

Приватная Google-таблица → Google Apps Script Web App (standalone, не через Extensions-меню) → агрегированный JSON (сумма за неделю, разбивка по РОПам, план) → фронтенд опрашивает раз в ~15 сек. Реальные ссылки и PIN — см. [MAP.md](./MAP.md#apps-script--бэкенд).

### Известные гэпы / отложено
- [ ] Не проверен напрямую точный формат кода отдела в реальной таблице (регистр/пробелы у «СР1» и т.д.) — если чей-то герой не бьёт при реальной продаже, смотреть сюда первым
- [ ] Круэлла имеет один арт — её реакции только код-анимации (пульс/искры)
- [ ] Скрудж — одна поза удара (остальным по 3)
- [ ] Дневные планы делятся поровну от недельного; возможность неравных долей/реальных «дней» пока не нужна
